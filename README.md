# Kali Linux Portfolio

A Kali Linux-inspired desktop environment portfolio built with React, showcasing cybersecurity projects, skills, and experience in an interactive terminal-style interface.

## Features

- 🖥️ **Desktop-like UI** - Kali Linux-inspired interface with draggable windows
- 💻 **Interactive Terminal** - Functional terminal emulator
- 🛡️ **Security-focused** - Showcases pentesting, red team, and security research work
- 📜 **Resume/CV** - Integrated resume viewer
- 📝 **Notepad** - Built-in notepad app
- 🎨 **Themed Widgets** - Calendar, network usage, system info, and Spotify widgets
- 📱 **Responsive Design** - Works on desktop and mobile

## Tech Stack

- React 18
- Material-UI (MUI)
- React Router
- Chart.js
- React Calendar
- React TSParticles

## Getting Started

### Prerequisites

- Node.js 14+
- npm or yarn

### Installation

```bash
cd kalilinux
npm install
```

### Development

```bash
npm start
```

Opens at [http://localhost:3000](http://localhost:3000)

### Build

```bash
npm run build
```

### Deploy to GitHub Pages

```bash
npm run deploy
```
